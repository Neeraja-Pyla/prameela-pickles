## 📌 About the Project

**Prameela Pickles** is a responsive business website designed to give the brand a strong online presence and provide visitors with an easy way to explore its products and learn about the business.

The website combines a clean modern interface with an authentic food-brand aesthetic.

---

## ✨ Features

* Responsive design
* Modern and clean user interface
* Product showcase
* Founder introduction
* Brand story
* Services / offerings section
* Contact section
* Responsive navigation
* Attractive product imagery
* Mobile, tablet, and desktop support
* Simple and user-friendly experience

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/Neeraja-Pyla/prameela-pickles.git
```

### Navigate to the Project

```bash
cd prameela-pickles
```

### Run the Website

Open `index.html` directly in your browser.

For development, you can use **Live Server** in VS Code.

---

## 🌍 Deployment

The website is deployed using **Netlify** and connected to the GitHub repository.

### Deployment Flow

```text
Local Project
     ↓
    Git
     ↓
  GitHub
     ↓
  Netlify
     ↓
Live Website
```

Updates pushed to the `main` branch can be deployed to the live website.
